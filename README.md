## Overview

FlowPilot is a polished multi-page SaaS landing website designed for a workflow and project-management product. It presents the product’s value proposition through a modern dashboard preview, feature sections, pricing plans, customer testimonials, FAQ content, and a contact/demo-request page.

The project focuses on clean visual hierarchy, responsive layouts, smooth transitions, and a professional product experience across desktop and mobile devices.

> Note: FlowPilot is a frontend demonstration project. Customer names, statistics, testimonials, and product claims are illustrative.


## Features

- Responsive desktop, tablet, and mobile layouts
- Multi-page navigation with React Router
- Modern SaaS hero section with dashboard preview
- Feature, pricing, about, FAQ, and contact pages
- Animated page transitions and scroll-based reveal effects
- Mobile navigation menu
- Reusable UI components for buttons, headings, CTAs, and branding
- Professional typography, spacing, gradients, and visual hierarchy
- Accessible focus states and semantic page structure
- Contact form interface with user-friendly validation states

## Pages Included

| Page | Description |
|---|---|
| Home | Product introduction, dashboard preview, highlights, testimonials, and CTA |
| Features | Overview of FlowPilot’s workflow, automation, analytics, and collaboration capabilities |
| Pricing | Plan comparison and pricing call-to-action |
| About | Product mission, values, and team-focused story |
| FAQ | Frequently asked questions in an easy-to-scan format |
| Contact | Demo request and contact interface |
| Not Found | Friendly 404 page for invalid routes |

## Tech Stack

- **React 19** — Component-based UI development
- **Vite** — Fast development server and production build tool
- **React Router DOM** — Client-side routing
- **Tailwind CSS 4** — Utility-first styling and responsive layouts
- **Framer Motion** — Smooth transitions and UI animations
- **Lucide React** — Clean, consistent iconography
- **CSS** — Custom design tokens, gradients, component styles, and responsive enhancements

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) version 18 or later
- npm

### Installation

```bash
# Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

# Open the project folder
cd Modern-Saas-Based-Website-main

# Install dependencies
npm install

# Start the development server
npm run dev
